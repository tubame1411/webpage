I DO ヘルプ

このアプリは、外付けの USB キーヤー（Arduino Keyer などの Winkey 互換キーヤー）を使用して、CW（電信）の移動運用およびロギングを大幅に効率化するためのツールです。また、ICOM IC-705 との Bluetooth 直接接続にも対応しており、外付けキーヤーなしでもスマートフォンと無線機だけで手軽に運用が可能です。アプリを起動すると初期設定画面が表示されますので各項目を入力してください。設定は保存されて次回起動時は最後に設定したものが表示されます。「設定を保存して定型文設定」または「設定を保存してはじめる」をタップするとメイン画面に遷移します。

メイン画面の操作

メイン画面の各インターフェース要素の機能は以下の通りです。

①
チェックのみ
チェックを入れると、Checkボタン押下時に送信を行わずに重複チェック（B4判定）のみを行います。チェックなしの場合は相手コールサインに続いて設定した内容を送出します。
②
接続 / 切断ボタン
USBキーヤーまたはIC-705との通信を開始・切断します。接続成功時はアイコンが青または緑色に点灯します。接続中にもう一度タップすると切断できます。
③
周波数・モード表示 & 同期（IC-705接続時）
IC-705接続時は、無線機側の現在周波数（MHz）とモードがリアルタイムで自動追従・表示されます。同期アイコンをタップすることで手動で再同期することも可能です。
④
STOP
現在送信中のメッセージを直ちに中断・停止します。
⑤
入力エリア
HisCall（相手局）、Date/Time（交信日時）、RSTr（受信レポート）、NRr（受信エクスチェンジ）を入力・表示します。相手コールサインを入力したらCheckボタンをタップします。
⑥
Check
コールサインの重複交信（B4）チェックを行い、日時を自動入力します。「チェックのみ」がオフの場合は、相手局への応答送信も行います。
⑦
定型文ボタン
設定画面であらかじめ登録した定型メッセージをワンタップで送信します。
⑧
メッセージ入力
任意のテキストを入力して送信するためのエリアです。
⑨
送信
メッセージ入力エリアに入力された内容を送信します。
⑩
登録・クリア
「登録」で交信内容をログに保存し、「クリア」で入力内容をリセットします。B4判定時は重複二重登録を防ぐため「登録」ボタンが自動的に無効化（グレーアウト）されます。

1. キーヤー・トランシーバーの接続

本アプリは「外付け USB キーヤー（Winkey互換）」を標準接続として設計されています。また、ICOM IC-705 をお持ちの場合は Bluetooth による直接接続にも対応しています。初期設定または画面右上のメニューから「接続設定」を開いて設定を行ってください。

1-1. 外付け USB キーヤー（Winkey互換）の接続 基本・標準

OTG アダプターなどを使用して、Arduino Keyer などの Winkey 互換キーヤーをスマートフォンに USB 接続して使用する基本構成です。

USB キーヤー接続時の特長
  • 物理ツマミとスライダーの双方向同期：キーヤー本体のポテンショメータ（速度調整ツマミ）を回すと、アプリ画面上の WPM スライダーがリアルタイムに連動します。また、アプリ側でスライダーを操作してもキーヤーの速度が即座に変更されます。
  • 安定した CW 送出：Winkey 互換プロトコルにより、正確なタイミングで符号が送出されます。

【接続手順】

  1. OTG ケーブルまたは変換アダプターを使用して、USB キーヤーをスマートフォンの USB ポートに接続します。
  2. アプリの「接続設定」画面で 「外付け USB キーヤー」 を選択します。
  3. 「USB接続」ボタンまたはメイン画面右上の接続ボタンをタップして通信を開始します。正常に接続されるとインジケーターが青色になります。
  4. 画面下部に WPM スライダーが表示され、ツマミやスライダーで速度調整しながら運用できます。

1-2. IC-705 との Bluetooth 接続

ICOM IC-705 とスマートフォンを Bluetooth でペアリングして直接接続するモードです。外付けキーヤーや接続ケーブルを用意することなく、スマートフォンから直接 CW の送出や交信コントロールが行えます。

IC-705 接続時の特長
  • 外付けキーヤー不要：スマートフォンから CI-V コマンド経由で IC-705 内蔵キーヤーへ直接 CW 送信指示を行います。
  • 周波数・モードの自動追随：IC-705 本体のダイヤルを回して周波数やモードを変更すると、アプリ画面の表示もリアルタイムに追従します。
  • 正確なバンド別 B4 判定：無線機から取得した現在の周波数帯（MHz帯）をもとに、同一バンドでの重複交信を自動判定します。
  • ※IC-705接続時は、送信速度（WPM）は無線機本体の設定値が反映されるため、アプリ画面の WPM スライダーは自動的に非表示になります。

【接続手順】

  1. 事前ペアリング：
    • IC-705 本体の MENU → SET → Bluetooth設定 で「Bluetooth」を ON にし、「ペアリング受信」にします。
    • スマートフォンの「設定」→「Bluetooth」を開き、検出された IC-705 をタップしてペアリングを完了させておきます。
  2. アプリで接続設定：
    • アプリの「接続設定」画面を開きます。
    • 接続モードで 「IC-705 (Bluetooth 直接接続)」 を選択します。
    • Bluetooth 権限の許可を求めるボタンが表示された場合はタップして許可します。
    • 「対象トランシーバー」のドロップダウンメニューから、ペアリング済みの IC-705 を選択します。
  3. 接続開始：
    • 「接続 (Connect)」ボタンをタップします。接続インジケーターが緑色（接続完了）に変われば完了です。
    • メイン画面上部に周波数とモードが表示され、CW 送信が可能になります。次回以降はメイン画面右上の接続アイコンをタップするだけで再接続できます。

キーボード入力について

入力時にソフトキーボードが開いた際、アルファベット入力（英語キーボード）に切り替えて、上矢印のキー（Shiftキー）を2回連続でタップすると、大文字入力（Caps Lock）に固定されるため大変便利です。

2. 交信の記録

メイン画面で相手局のコールサインを入力し、「チェック」をタップすると同一バンド内での「B4（重複交信）」の判定を行い、現在日時を自動入力して相手局のコールサイン・RSTを送出します。

  • チェックのみ：チェックボックスが ON の場合は、CW 送出は行わずに B4 チェックと日時入力のみを行います。
  • B4判定時：既に交信済みの場合は相手コールサインと「B4」を送出し、二重登録を防止するため「登録」ボタンが自動的に無効化（グレーアウト）されます。
  • ログの登録：RSTr（受信レポート）やエクスチェンジを入力して「登録」ボタンをタップすると、交信ログが端末内データベースに保存されます。登録完了後、送信レポート（RSTs）は自動的に「599」にリセットされます。

3. 定型文とタグ

「定型文設定」画面で、ボタンに割り当てる送信内容を編集できます。以下のタグを使用すると、入力された情報や無線機の状態を自動的に埋め込んで送出することができます：

  • • {MyCall} 自局のコールサイン
  • • {HisCall} 相手局のコールサイン
  • • {REPORT} レポート（送付）
  • • {NUMBER} エクスチェンジ（自動インクリメント対応）
  • • {CONTEST_NAME} コンテスト名
  • • {GREETING} あいさつ (GEなど)
  • • {JCC} / {JCG} JCC/JCG番号
  • • {POTA} / {SOTA} POTA/SOTAリファレンス

4. Turbo HAMLOG とのログ同期（CwLogSync）

スマートフォンで記録した交信ログと、Windows PC の定番ログソフト「Turbo HAMLOG」を、USB ケーブル 1 本で完全オフライン・ワンクリックで相互同期できる専用連携ツール「CwLogSync」をご利用いただけます。

手動での CSV エクスポートやインポートの手間は一切不要で、ボタン 1 つで Turbo HAMLOG へ直接交信データが書き込まれます。

CwLogSync 同期機能の特長
  • 完全オフライン同期：インターネット接続は不要。USB テザリングを利用して安全かつ高速にデータ転送を行います。
  • 完全ミラー同期：スマートフォンの未送信ログを HAMLOG へ登録した後、HAMLOG 側の最新全データ（PC側で修正・削除したデータやお名前、QTH等）をスマートフォン側へ書き戻します。
  • 移動先で過去ログを瞬時に参照：HAMLOG の全交信実績がスマートフォン内に保持されるため、電波の届かない山頂などの移動先でも、過去の交信実績（相手のお名前、QTH、B4判定）をオフラインで瞬時に参照できます。
  • 未送信ログの自動保護：スマートフォン側で新しく記録した未送信ログは、同期完了前に消えることがないよう安全に保護されます。
  • 自動バックアップ：同期直前に、HAMLOG フォルダ内のデータベース（*.hdb, *.mst 等）を日付付きで CwLogSync_Backups/ フォルダへ自動退避します。

【日常の同期手順】

  1. スマホと PC を接続：USB ケーブルでスマートフォンと PC を接続します。
  2. USBテザリングを ON：スマートフォンの「設定」または通知バーから 「USBテザリング」 を ON にします。
  3. スマホでアプリを起動：スマートフォン側で 「CW Log」アプリを起動 しておきます（アプリ起動中のみ待機状態となります）。
  4. HAMLOG を終了：PC の Turbo HAMLOG が起動している場合は終了 します（※データ安全保護のため）。
  5. 同期ツールを起動：PC で解凍したフォルダ内の CwLogSync.exe を起動します。
  6. 同期の実行：接続ステータスが「● スマホ接続完了」に変わったら、「▶ スマホと同期を開始」 ボタンをクリックします。
  7. 数秒で「同期完了！」と表示されます。PC の Turbo HAMLOG を起動し、データが正しく反映されていることをご確認ください。
❓「USBテザリング待機中...」から進まないときのチェックリスト 接続インジケーターが赤色のまま変わらない場合は、以下をご確認ください：
  • スマートフォン側でアプリが起動していますか？ アプリが起動している間のみ同期窓口がオープンします。
  • USBテザリングが ON になっていますか？ ケーブルを抜き差しすると自動で OFF になる機種があります。ONになっているか再確認してください。
  • USBケーブルは通信対応ですか？ 100円ショップ等の「充電専用ケーブル」では通信できません。データ通信対応のケーブルをお使いください。

※初回起動時に Windows Defender の「WindowsによってPCが保護されました」画面が表示された場合は、「詳細情報」→「実行」をクリックしてください。

5. ログのエクスポートとインポート（CSV / ADIF）

PC 連携ツール（CwLogSync）を使用しないスタンドアローン運用や、他のログ管理ソフト・Web サービスとの連携、手動バックアップに利用できる標準機能です。

  • ログのエクスポート：
    • Turbo HAMLOG 互換 CSV：Shift-JIS 形式の CSV ファイルとして書き出し、Turbo HAMLOG の CSV インポート機能へそのまま取り込み可能。
    • ADIF（.adi）：世界標準のログ形式でエクスポートし、eQSL、LoTW、各種コンテスト集計ソフト等へインポート可能。
  • CSVファイルのインポート：
    • Turbo HAMLOG 等から書き出した過去ログ CSV（Shift-JIS）を選択して端末内に一括取り込み可能（同一交信の二重取り込み防止機能付き）。
